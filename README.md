# ContactApp
ASP.net 4.3 assignment<br>

Contains a contact page that allows the input of a name, email and message with validation.<br>
All fields are required.<br>
The email field is validated to ensure a proper email is stored.<br>
The message field has a maximum message length of 300 characters.<br>
